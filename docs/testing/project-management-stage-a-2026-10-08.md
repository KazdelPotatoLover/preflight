# 项目管理与自主认领首版验证

日期：2026-10-08。范围：[v0.2 方案](../plans/autonomous-collaboration-v0.2.md)的阶段 A 首版，基于 `bb8c85d` 增量开发。不是完整 v0.2，也不是两个外部模型持续自主执行的试验。

## 已交付

- Project 与默认项目兼容升级、简单 Milestone、需求/缺陷 Goal 的待办/就绪/暂停/取消/归档、优先级、业务责任人、计划日期与授权审计。
- 人类工作台管理计划和未认领任务；Agent 使用相同领域规则拆解、读取、认领任务。列表/看板显示执行责任、依赖阻塞和目标条件覆盖缺口。
- 子任务独立验收与目标条件映射，定义版本改变使旧验收与依赖完成记录失效。同项目允许跨目标依赖，禁止自引用和环。
- 原子主责任租约、续期、主动释放、过期接管、旧 epoch 写入拒绝，保留参与者和历史。
- 历史知识检索/游标分页、失败条件与证据、反驳/替代引用。普通协商继续由 Agent 提交证据达成一致。

## 哪些是真实的，哪些是测试夹具

数据库、HTTP/MCP transport、独立成员认证、并发请求、版本冲突、租约检查、持久化和浏览器操作均真实执行。租约过期通过注入领域时钟向前推进十分钟后校验，未实际等待十分钟，也未伪造数据库返回。

任务完成用 fixture SHA、声明命令和文本证据验证协议的完整性规则；它们不是已执行的业务改动、真实远端 SHA 或独立 CI 结果。服务器始终标记 `agent_report`，里程碑 `delivery_state=not_independently_verified`。上面的 TypeScript/集成/浏览器/构建命令确实执行过。

管理测试的角色动作由脚本安排，验证共享协议和失败路径，不证明模型自行发现、持续执行或零协调。没有把 SDK 客户端当作自主模型试验。

## 尚待完成

阶段 B：持久更新消费/确认/去重、真实客户端适配器、自动心跳/恢复、协商缺席超时与无需催办的持续推进。

阶段 C：贡献候选、Git/CI 独立事实、集成结果、目标整体验收、里程碑交付/返工与重新打开。容量限制、标签/全文搜索和更完整筛选也未交付。当前暂停只限制服务端新认领/推进，不能停止外部进程；优先级是发现顺序，不是强制调度。

本版可以试用“规划项目 → 就绪目标 → 提出子任务 → Agent 认领 → 上报执行/知识 → 管理视图汇总”的管理流程，还不能声称完整替代 devboard 或完成持续自主交付。
